# Template Task Baru (Folder Mode)

> Salin folder `_template/` menjadi `tasks/NN-slug/`, lalu isi tiap file.
> Hapus baris ini setelah diisi.

## Isi tiap file

* `README.md` — salin dari template, sesuaikan judul + Status.
* `spec.md` — Objective, Context, Scope (In/Out), Dependencies.
* `flow-requirements.md` — User Flow (Diagram, Steps, Alternate/Error, mapping) + Requirements.
* `domain-api-ui.md` — Domain + API + UI.
* `acceptance-tasks.md` — Acceptance Criteria (Given/When/Then) + Tasks checklist + Test Plan.
* `verification.md` — Verification + Assumptions + Open Questions + Related Knowledge + Change Log.
