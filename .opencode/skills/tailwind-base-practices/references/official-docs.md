## v4 Changes Summary
- CSS-first configuration (no more `tailwind.config.js`)
- New `@theme` directive for theme variables
- New `@utility` directive for custom utilities
- New `@variant` directive for custom variants
- No preflight by default (better for component libraries)
- New gradient syntax: `bg-linear-to-r` instead of `bg-gradient-to-r`
- Container is now a built-in utility
