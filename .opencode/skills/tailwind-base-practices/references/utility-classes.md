# Tailwind CSS v4 - Utility Classes

## Layout
```html
<div class="flex items-center justify-between">...</div>
<div class="grid grid-cols-3 gap-4">...</div>
<div class="block hidden">...</div>
```

## Spacing
```html
<div class="p-4 m-2 px-6 py-3">...</div>
<!-- Custom: p-[value] mx-[value] -->
<div class="p-[1.25rem] m-[2px]">...</div>
```

## Typography
```html
<h1 class="text-2xl font-bold text-gray-900">Title</h1>
<p class="text-sm text-gray-600 leading-relaxed">Text</p>
<span class="font-medium text-primary">Label</span>
```

## Colors
```html
<div class="bg-white text-black">...</div>
<div class="bg-blue-500 text-blue-100">...</div>
<div class="bg-primary text-primary-foreground">...</div> <!-- theme variable -->
```

## Borders & Rounded
```html
<div class="border border-gray-200 rounded-lg">...</div>
<div class="rounded-full">...</div>
```

## Sizing
```html
<div class="w-full h-screen">...</div>
<div class="w-64 min-h-[200px] max-w-2xl">...</div>
```

## Positioning
```html
<div class="relative absolute inset-0">...</div>
<div class="fixed sticky">...</div>
```

## Flexbox
```html
<div class="flex flex-col gap-2 items-center justify-center">...</div>
<div class="flex-1 shrink-0 grow">...</div>
```

## Grid
```html
<div class="grid grid-cols-3 grid-rows-2 gap-4">...</div>
<div class="col-span-2 row-span-1">...</div>
```

## Z-index
```html
<div class="z-0 z-10 z-50">...</div>
```

## Opacity
```html

```

## Shadow
```html
<div class="shadow-sm shadow-md shadow-lg shadow-xl">...</div>
```

## Transitions & Animations

```

## Cursor & Interaction

```
